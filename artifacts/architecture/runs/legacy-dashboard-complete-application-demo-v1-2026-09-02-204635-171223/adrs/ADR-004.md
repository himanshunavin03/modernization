# ADR-004: Forms and State Management Strategy

## Status

Selected Target Architecture

## Context

This decision applies the approved requirements and target enterprise policy without changing existing business API contracts.

## Decision

- Prefer signal-oriented forms for suitable new forms after target API validation.
- Own Dashboard state in focused injectable signal stores.

## Alternatives Considered

- NgRx (NOT_SELECTED): Current state complexity does not justify it.

## Why Selected

- The strategy aligns with signal state, but no Dashboard form workflow should be fabricated.
- Known state is feature-scoped and does not require a global event architecture.

## Consequences

- Signal-aligned validation state
- Low ceremony
- Feature ownership

## Tradeoffs

- Maturity and team readiness need validation
- Cross-domain workflows may require reevaluation
