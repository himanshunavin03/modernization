# ADR-004: Router with lazy feature routes

## Status

Recommended

## Context

Multiple approved Feature boundaries map naturally to route-level loading.

## Decision

Use lazy route boundaries for approved Features and functional guards where access checks apply.

## Alternatives

- Reassess if approved requirements change.
