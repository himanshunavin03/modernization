01 · FRONTEND

Modern Angular foundation

Angular 22, TypeScript, standalone components, functional APIs, and modern template control flow.

02 · WORKSPACE

Governed Nx boundaries

Nx monorepo with domain-oriented, shared design-system, and API data-access libraries.

03 · REACTIVITY

Signals with RxJS

Signals own synchronous and derived UI state; RxJS owns HTTP cancellation and asynchronous composition.

04 · RUNTIME

Zoneless, with a verified fallback

Zoneless Angular is selected after dependency compatibility checks; Zone.js remains the explicit fallback.

05 · ROUTING + RENDERING

Lazy CSR application

Angular Router, lazy Feature routes, functional guards, code splitting, and client-side rendering.

06 · INTEGRATION

Typed request boundaries

Typed HttpClient and functional interceptors propagate organization, correlation, and normalized errors.

07 · ENTERPRISE EDGE

Gateway + BFF

Provider-neutral policy and Angular-specific orchestration sit in front of preserved business APIs.

08 · QUALITY

Accessible and observable delivery

WCAG-oriented design, unit/component tests, Playwright, correlated telemetry, and Nx-aware CI gates.

SELECTEDAngular 22 · Nx · Signals + RxJS · Zoneless · CSR · Gateway + BFF
EXPLICIT LIMITSNgRx, microfrontends, and Module Federation are not selected · Authentication provider requires clarification
